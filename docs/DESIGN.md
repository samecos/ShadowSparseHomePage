# 设计规范

## 气质

安静、清冷、有呼吸感。像一张被仔细整理过的桌面，而不是一个数据大屏。

## 色彩

| Token | Value | 用途 |
| --- | --- | --- |
| `--paper` | `#F6F7F8` | 页面底色，雾白 |
| `--paper-soft` | `#FBFCFC` | 玻璃面板 / 内容底 |
| `--paper-deep` | `#EDF0F2` | 图片占位、分隔 |
| `--ink` | `#191D22` | 主文字，墨色 |
| `--ink-soft` | `#4A525C` | 次级文字 |
| `--ink-faint` | `#8B939C` | 元信息、弱文字 |
| `--accent` | `#658092` | 冷灰蓝，交互强调 |
| `--accent-deep` | `#3F586A` | 深一档强调色 |
| `--accent-pale` | `#DDE5EA` | 轻柔选区 / hover 底色 |

## 字体

- 正文：`SF Pro Text → PingFang SC → 系统无衬线`
- 标题 / 数字：`Songti SC → STSong → 系统衬线`
- 代码 / 坐标：`SFMono-Regular → Roboto Mono`

字号策略：

- 页面主标题：`clamp(30px, 4.4vw, 52px)`
- 首页主标题：`clamp(36px, 6vw, 76px)`
- 正文：`15px / 1.75`
- 元信息：`10-12px`，字距 `0.1em` 左右

## 间距与形状

- 页面最大宽度：`1240px`
- 桌面左右留白：`28px`
- 区块间距：`72-96px`
- 卡片圆角：少用；面板最多 `14-24px`
- 主要分隔方式是 `1px` 细线，而不是阴影
- 阴影只用于地图浮层和少量玻璃面板，必须非常淡

## 图片

- 统一降低饱和度（约 `0.68-0.8`）
- hover 时轻微恢复饱和度和放大（不超过 `1.05`）
- 抽象占位图统一使用低饱和冷色渐变
- 照片可以换，但建议先做一层统一的色调处理

## 动效

- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)`
- 入场：淡入 + 上移 `14px`，`0.85s`
- 图片 hover：`0.8-0.9s`
- 所有动效必须尊重 `prefers-reduced-motion`
- 不做弹跳、闪烁、强视差

## 禁止

- 大面积高饱和渐变
- 密集卡片瀑布流堆叠
- 营销式大字号感叹句
- 过多 badge、过多圆角、过多阴影
- 自动播放视频或声音
